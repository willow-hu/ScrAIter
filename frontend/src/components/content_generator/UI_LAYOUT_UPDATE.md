# Content Generator UI 布局更新说明

## 🎨 新的UI布局设计

根据用户需求，ContentGenerator组件进行了全面的UI重构，采用更现代化和实用的布局设计。

## 🔄 主要变更

### ✅ 已实现的改进

1. **删除顶部工具栏**
   - 移除了独立的工具栏区域
   - 将"修改知识库"按钮移至节点编辑卡片的操作按钮组中

2. **参考资料默认显示**
   - 删除"查看参考资料"按钮
   - 参考资料面板常驻右侧显示
   - 生成内容后自动加载参考资料

3. **新的参考资料面板**
   - 创建了 `ReferencePanel.jsx` 组件
   - 支持分页浏览，一次显示一条资料
   - 卡片下方显示分页控制器：`< 1/5 >`
   - 最多显示5条参考资料
   - 显示来源文件和相关度分数

4. **删除完成进度卡片**
   - 移除右侧的"完成进度"卡片
   - 进度信息已在节点编辑卡片标题中显示

5. **重新布局信息卡片**
   - "项目信息"和"使用说明"卡片移至主屏幕下方
   - 采用并排布局（各占50%宽度）
   - 更新使用说明，包含参考资料的使用方法

### 🎯 布局优势

1. **更高效的空间利用**
   - 主要内容区域更宽敞
   - 参考资料实时可见，提升工作效率

2. **更流畅的工作流程**
   - 编辑节点时可直接查看参考资料
   - 减少弹窗切换，提升用户体验

3. **更清晰的视觉层次**
   - 主要功能区域突出显示
   - 辅助信息有序排列在下方

## 🎨 样式系统

### 新增样式类
- `.reference-panel` - 参考资料面板样式
- `.bottom-info-cards` - 底部信息卡片容器样式
- 响应式设计适配不同屏幕尺寸

### 色彩方案
- **节点编辑卡片**: 蓝色渐变头部 (#1890ff → #36cfc9)
- **参考资料面板**: 绿色渐变头部 (#52c41a → #73d13d)
- **操作按钮**: 功能性色彩区分（生成-绿色，导出-橙色）

## 🔧 技术实现

### 新增组件
- `ReferencePanel.jsx` - 独立的参考资料展示组件
  - 支持分页浏览
  - 空状态处理
  - 响应式设计

### 状态管理优化
- 移除了 `referencesVisible` 状态
- 优化了参考资料的加载逻辑
- 节点切换时自动清空参考资料

### 布局系统
- 使用 Ant Design 的 Grid 系统（Row/Col）
- 响应式断点设计
- 弹性布局确保卡片高度一致

## 📱 响应式适配

布局在不同设备上的表现：

- **桌面端** (≥1200px): 完整的两列布局
- **平板端** (768px-1200px): 调整间距和比例
- **移动端** (<768px): 垂直堆叠布局

## 🚀 使用指南

1. **内容生成工作流程**:
   ```
   编辑节点信息 → 点击"生成内容" → 查看参考资料 → 编辑优化内容 → 保存
   ```

2. **参考资料浏览**:
   - 生成内容后自动显示参考资料
   - 使用左右箭头切换不同片段
   - 查看来源文件和相关度评分

3. **知识库管理**:
   - 点击"修改知识库"按钮打开管理面板
   - 上传、删除文件并重建知识库
